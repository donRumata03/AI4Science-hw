# Library

`catalog.json` pins three original PDFs, their versions and SHA-256.
`retrieval/corpus.jsonl` contains 27 local title/abstract records, with separate
text files, OpenAlex provenance, vectors and ranked retrieval outputs. This follows
the own-topic section of search_lab.ipynb; it is not a 27-PDF full-text review.
Source notes preserve review/access scope. Do not edit original PDFs.
